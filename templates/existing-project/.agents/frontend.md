# Frontend

Use componentes coesos em React e TypeScript quando aplicável; prefira estado local e contratos tipados. Garanta acessibilidade por teclado, semântica e nomes acessíveis, responsividade e testes de interação. Meça desempenho com métricas adequadas, evitando carregamento desnecessário. Para SEO técnico, considere indexabilidade, metadados, URLs canônicas e renderização conforme o produto. Trate conteúdo não confiável com segurança e evite expor segredos no navegador.
