# Security

Defina requisitos e controles de segurança por threat modeling e riscos OWASP aplicáveis. Adote autenticação, autorização, menor privilégio, criptografia, validação de entradas, proteção de dados e gestão de segredos adequadas. Registre riscos e decisões; DevSecOps automatiza a verificação e DevOps constrói o fluxo de entrega.
